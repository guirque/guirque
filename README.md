#  Bem-vindo(a)! 👋

Sou desenvolvedor web, formado em Ciência da Computação. Meus conhecimentos e interesses são, principalmente, em:
- Desenvolvimento Full-Stack;
- Princípios de Design UI/UX;
- Cloud Computing;
- Sistemas integrados com Inteligência Artificial.

Atualmente, estou em busca de minha primeira oportunidade empregatícia, a fim de aplicar a programação com foco no cliente. Em paralelo, atuo no desenvolvimento de um projeto de Deep Learning na área de enfermagem, para um artigo.
